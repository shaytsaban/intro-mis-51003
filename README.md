# מבוא למערכות מידע לניהול (51003)

אתר הקורס, המרכז האקדמי שערי מדע ומשפט, סמסטר א׳ תשפ״ז. ד״ר שי צבאן.

Excel מאפס לסטודנטים לניהול מערכות בריאות. שיעור 1 הוא מפגש היכרות חי (12.11.2026), עם מצגת שמסבירה בצילומי מסך איך לומדים בקורס. משיעור 2 ואילך, לכל שיעור: מצגת אינטראקטיבית עם גיליונות Excel חיים והדגמות מונפשות, סיכום PDF, קובץ תרגול וקובץ פתרונות, והקלטה.
